PhotoCull AI - Kiến trúc Hệ thống

1. Mục tiêu

Tái cấu trúc (Refactor) file monolith App.tsx để cải thiện khả năng bảo trì và mở rộng.

2. Tách Component

Chúng tôi sẽ tách các component sau:

  • Header: Chứa logo, thống kê và các hành động nhanh.
  • Toolbar: Chứa các bộ điều khiển tìm kiếm, sắp xếp và bộ lọc.
  • MainView: Hiển thị vùng thả file (drop zone) và danh sách ảo (virtualized list).

3. Quản lý Trạng thái

Chúng tôi đề xuất áp dụng Zustand để quản lý trạng thái tập trung, nhẹ nhàng nhằm loại bỏ việc truyền prop lòng vòng (prop drilling).
