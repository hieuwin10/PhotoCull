1. Web Worker Pool — Xử lý Song song

Vấn đề Hiện tại

Tất cả việc tạo hash đều chạy trên luồng chính → 10k ảnh làm đóng băng trình duyệt hơn 80 giây

Giải pháp: Pool Worker 4 luồng

Luồng chính (Main Thread) Pool Worker (4 luồng) ┌────────────┐ ┌──────────────┐ │ Hàng đợi │──điều phối──→ │ Worker #1 │ ← Hash + Laplacian │ 10,000 │ │ Worker #2 │ ← OffscreenCanvas │ ảnh │ │ Worker #3 │ ← Truyền dữ liệu không sao chép │ │◀──kết quả─── │ Worker #4 │ ← ImageBitmap.close() └────────────┘ └──────────────┘ Thanh tiến trình hiển thị ✅ UI vẫn mượt 60fps ✅
Chỉ sốHiện tại (1 luồng)Pool Worker (4 luồng)

5,000 ảnh~40s (đóng băng)~10s (mượt mà)
10,000 ảnh~80s (đóng băng)~20s (mượt mà)

2. Vòng đời ObjectURL — Sửa lỗi Rò rỉ Bộ nhớ

Chuỗi rò rỉ hiện tại

createObjectURL(file) → lưu trong state → xóa ảnh → URL VẪN SỐNG → RAM KHÔNG BAO GIỜ ĐƯỢC GIẢI PHÓNG
Với 10k ảnh, xóa 3k ảnh = rò rỉ khoảng 15GB RAM

Giải pháp: Quản lý URL tập trung

class ObjectURLManager {
  registry: Map<imageId, url>
  refCount: Map<url, count>
  
  create(id, file) → URL     // Đăng ký + theo dõi
  release(id)      → void    // Giảm số lượng tham chiếu, thu hồi nếu bằng 0
  revokeAll()      → void    // Dọn dẹp toàn bộ (khi làm trống thùng rác)
}

📋 Danh sách Kiểm tra Đầy đủ cho Phiên Code Tiếp theo

Phase 1: Sửa lỗi & Hiệu suất

  • Sửa process.env.API_KEY → import.meta.env
  • Sắp xếp file trước khi nhóm
  • Thêm lượt Cứu hộ ảnh lạc
  • Pool Worker Web để tạo hash
  • Quản lý ObjectURL (thu hồi khi xóa/thùng rác)
  • Chia nhỏ App.tsx thành hơn 5 component
  • Chia nhỏ ImageModal.tsx thành hơn 6 component
  • Bảo vệ vòng lặp hàng loạt while(true)
  • Hàng đợi yêu cầu API toàn cục

Phase 2: Tích hợp Ollama

  • Tạo file ollamaService.ts
  • Truyền phát (Streaming) SHA256 cho file lớn
  • Upload blob + tạo API model
  • Trình hướng dẫn thiết lập UI
  • Tự động phát hiện CORS
  • Giao diện AIProvider + OllamaProvider

Phase 3: OpenRouter & Hoàn thiện

  • Triển khai OpenRouterProvider
  • Chuỗi dự phòng tự động
  • Bộ nhớ cache IndexedDB
  • Điểm số độ nét Laplacian
  • Phân tích cú pháp EXIF DateTimeOriginal
