1. Quy trình thiết lập tự động

1

Tự động phát hiện Ollama

Ping GET localhost:11434/api/tags với timeout 3 giây. Nếu OK → Ollama đang chạy. Nếu thất bại → hiển thị hướng dẫn cài đặt.

2

Kiểm tra các Model Vision hiện có

Lọc danh sách model theo các từ khóa vision đã biết: llava, vision, minicpm-v, moondream, qwen2.5-vl, granite-vision. Nếu tìm thấy → sử dụng trực tiếp, bỏ qua bước 3.

3

Tự động Import file .gguf

Hiển thị trình hướng dẫn (wizard) → Người dùng chọn file .gguf qua trình duyệt file → Ứng dụng tính toán SHA256 (streaming, không gây tràn bộ nhớ OOM) → Tải blob lên Ollama → Tạo model qua API. Hiển thị thanh tiến trình đầy đủ.

4

Kiểm tra & Lưu cấu hình

Gửi prompt thử nghiệm để xác minh model hoạt động → Lưu tên model vào localStorage → Lần sau mở ứng dụng sẽ tự động sử dụng model đã lưu.

2. Các thách thức kỹ thuật cốt lõi

2.1 Streaming SHA256 (Cho file dung lượng lớn tới 30GB)

Vấn đề: file.arrayBuffer() tải toàn bộ file vào RAM → file 30GB = sập tab ngay lập tức.

Giải pháp: Sử dụng thư viện hash-wasm (dựa trên WebAssembly) để hash file theo từng khối 64MB.

const { createSHA256 } = await import('hash-wasm');
const hasher = await createSHA256();
hasher.init();

const CHUNK = 64 * 1024 * 1024; // 64MB
for (let i = 0; i < Math.ceil(file.size / CHUNK); i++) {
  const slice = await file.slice(i*CHUNK, (i+1)*CHUNK).arrayBuffer();
  hasher.update(new Uint8Array(slice));
  onProgress((i+1) / totalChunks * 100);
}
return hasher.digest('hex');

2.2 Tải lên với thanh tiến trình

Sử dụng XMLHttpRequest thay vì fetch để theo dõi tiến trình tải lên:

const xhr = new XMLHttpRequest();
xhr.open('POST', `${OLLAMA}/api/blobs/sha256:${digest}`);
xhr.upload.onprogress = (e) => onProgress(e.loaded/e.total*100);
xhr.send(file); // Stream trực tiếp, không copy bộ nhớ

✅ Ollama cũng hỗ trợ kiểm tra HEAD để bỏ qua việc tải lên lại nếu blob đã tồn tại.

2.3 Cấu hình CORS

⚠️ Trình duyệt chặn các yêu cầu đến localhost:11434 theo mặc định.

PhotoCull sẽ tự động phát hiện lỗi CORS và hiển thị cách sửa 1-click:
setx OLLAMA_ORIGINS "*" → khởi động lại Ollama → xong vĩnh viễn.

4. Kiến trúc Đa nhà cung cấp (Multi-Provider)

interface AIProvider {
  name: string;
  analyzeGroup(images, prompt): Promise<AnalysisResult>;
  enhanceImage(image, instructions): Promise<string>;
  isAvailable(): Promise<boolean>;
}

// Tự động chọn provider tốt nhất hiện có:
// Ưu tiên 1: Ollama local (miễn phí, nhanh, riêng tư)
// Ưu tiên 2: Gemini API (nếu có API key)  
// Ưu tiên 3: OpenRouter (dự phòng gói miễn phí)

✅ Code 1 lần → chạy được với bất kỳ provider nào. Người dùng chọn trong Cài đặt.
