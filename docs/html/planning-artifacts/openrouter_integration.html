Nhà cung cấp #3

🌐 Tích hợp OpenRouter

1 API key → hơn 100 mô hình. Các mô hình thị giác miễn phí làm dự phòng cho phân tích ảnh.

1. OpenRouter là gì?

🔑 Tính năng Chính

  • Cổng kết nối API hợp nhất — 1 key, hơn 100 mô hình
  • Định dạng tương thích với OpenAI
  • Gói miễn phí có hỗ trợ các mô hình thị giác (vision)
  • Tự động định tuyến: openrouter/free
  • Không cần cài đặt phần mềm

📊 Giới hạn Tần suất

Miễn phí (không nạp tiền)20 RPM (Yêu cầu/Phút), 50 RPD (Yêu cầu/Ngày)
Nạp $1020 RPM, 1000 RPD
Các mô hình trả phíChỉ theo giới hạn của nhà cung cấp

2. Đặc tả API

POST https://openrouter.ai/api/v1/chat/completions

Headers:
  Authorization: Bearer sk-or-v1-xxx
  Content-Type: application/json
  HTTP-Referer: https://photocull.app
  X-Title: PhotoCull AI

Định dạng Yêu cầu Thị giác (Vision Request)

{
  "model": "openrouter/free",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "Phân tích những bức ảnh này..." },
      { "type": "image_url", 
        "image_url": { "url": "data:image/jpeg;base64,{BASE64}" }}
    ]
  }],
  "response_format": { "type": "json_object" }
}

Kiểm tra Key & Hạn ngạch còn lại

GET https://openrouter.ai/api/v1/key
→ { "remaining": 42, "limit": 50, "usage": 8 }

Response Headers:
  X-RateLimit-Remaining: 18
  X-RateLimit-Reset: 1718000000
  Retry-After: 30  (khi gặp lỗi 429)

4. Chiến lược Xử lý Lỗi

400Yêu cầu không hợp lệGiảm số lượng ảnh, thử lại
401Key không hợp lệHiển thị lỗi key trong Cài đặt

429Bị giới hạn tần suấtLùi lại theo cấp số nhân (Exponential backoff) + thử mô hình khác

503Quá tảiChờ số giây được chỉ định trong Retry-After

Chuỗi Dự phòng Tự động

Yêu cầu thất bại trên openrouter/free (429) ↓ thử lại với google/gemma-4-31b:free (429) ↓ thử lại với nvidia/nemotron-3-nano:free (429) ↓ tất cả đều thất bại Hiển thị: "Tất cả mô hình đều bận. Thử lại sau 1 phút."

6. Các Hạn chế Chính

❌ Không hỗ trợ Tạo ảnh

Không thể thực hiện Magic Fix hoặc Biến thể màu sắc. Chỉ có Gemini hỗ trợ những tính năng này.

❌ 50 yêu cầu/ngày (miễn phí)

Phân tích hàng loạt hơn 100 nhóm sẽ làm cạn kiệt hạn ngạch hàng ngày. Nạp $10 → 1000 yêu cầu.

⚠️ Độ trễ cao hơn

Ủy quyền kép: Trình duyệt → OpenRouter → Nhà cung cấp. ~2-5 giây cho mỗi yêu cầu.

⚠️ Mô hình thay đổi

Các mô hình miễn phí được luân phiên. Ứng dụng phải tự động phát hiện qua API, không nên mã hóa cứng.
