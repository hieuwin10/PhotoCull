How-To Guides

Các hướng dẫn ngắn để làm đúng một việc trong quá trình phát triển PhotoCull.

Thêm tính năng

Đặt feature vào module đúng, cập nhật type, store, service và test.

Tích hợp AI provider

Dùng `AIService` và adapter để tránh UI phụ thuộc vào Gemini SDK.

Viết kiểm thử

Ưu tiên store, AI mock, IndexedDB, keyboard shortcut và grid ảo hóa.

Build và vận hành

Build `dist/`, bảo vệ API key, kiểm soát upload ảnh và smoke test.
