Vòng đời phát triển

Yêu cầu Chốt người dùng chính, luồng chọn lọc ảnh, tiêu chí MVP và yêu cầu quyền riêng tư.
Kiến trúc Tách UI, feature module, Zustand store, service layer, AI adapter và IndexedDB.
Hiện thực Xây theo lát dọc: import ảnh, grid ảo hóa, chọn lọc, AI, lưu phiên, so sánh.
Kiểm thử Unit test cho store/service, component test cho UI, integration test cho IndexedDB và AI mock.
Vận hành Build artifact tĩnh, bảo vệ API key, kiểm soát upload ảnh và smoke test trước phát hành.

Kiến trúc mục tiêu

Lớp Trách nhiệm Ghi chú
UI Hiển thị grid, compare view, toolbar, panel AI. Không gọi trực tiếp Gemini hoặc IndexedDB.
Store Quản lý ảnh, selection, rating, kết quả AI và trạng thái UI. Dùng selector để giảm re-render.
Service AI, storage, image processing, export. Che giấu SDK và IO khỏi component.
Types Contract dữ liệu cho ảnh, nhóm ảnh, AI result, session. Là nguồn ổn định cho AI/dev khi lập trình.

Vận hành và bảo mật

PhotoCull nên vận hành theo hướng local-first. Ảnh không được tự động tải lên cloud. Khi bật Gemini hoặc provider cloud khác, UI cần thể hiện rõ ảnh sẽ được gửi ra ngoài.

  • Không commit API key hoặc file `.env`.
  • Không log tên file, metadata nhạy cảm hoặc nội dung ảnh.
  • AI provider phải đi qua adapter để dễ thay Gemini, local model hoặc mock.
  • Build production nằm trong `dist/` và cần smoke test trước phát hành.
